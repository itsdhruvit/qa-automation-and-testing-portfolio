# Software QA & Test Automation Portfolio

Welcome to my Software Quality Assurance portfolio. This repository demonstrates structured manual test design, end-to-end UI automation using **Playwright**, and REST API validation.

## What's Inside
1. **`test-cases/checkout-and-login-test-cases.md`** — Structured manual test suite covering functional, negative, boundary, and regression scenarios.
2. **`tests/login-and-cart.spec.js`** — Automated end-to-end UI tests written in JavaScript using Playwright.
3. **`api/user-api-validation.spec.js`** — Automated REST API checks validating HTTP status codes, JSON response schemas, and error handling.

## Tech Stack & QA Tooling
* **Test Automation:** Playwright, JavaScript
* **API & Data Validation:** REST APIs, Postman, JSON assertions, SQL
* **Test Management & Defect Tracking:** Jira, STLC / SDLC, Agile / CI-CD (Git)
